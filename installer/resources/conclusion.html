PangolinGit is installed

Right-click any folder or file inside a Git repository in Finder to use the Git Commit…, Git Show Log and PangolinGit ▸ commands. PangolinGit runs in the background; there is no app to start. The first command you use walks you through a short setup.

If the commands or badges don't appear, open System Settings ▸ General ▸ Login Items & Extensions and make sure PangolinGit is enabled both under Finder extensions and in the list of apps allowed to run in the background.

To uninstall, run /Applications/PangolinGit.app/Contents/Resources/uninstall.sh in Terminal.
