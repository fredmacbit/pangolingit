PangolinGit

A macOS port of TortoiseGit: Git status badges and Git commands right in the Finder context menu, plus a full set of Git dialogs.

This installer will:

  • install PangolinGit in your Applications folder;
  • register and enable its Finder extension (badges, context menu, toolbar button);
  • register the PangolinGit status agent, a small background helper that computes badges;
  • restart Finder so the context menu appears, then open PangolinGit for a short setup.

PangolinGit uses the git command-line tool. If it isn't installed yet, run xcode-select --install or brew install git.
